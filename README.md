## 🚀 Local Development

Start a local server:

```bash
# Python 3
python3 -m http.server 3000
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 🌐 Deploying to FlexiFunnels

1. Copy the contents of `bundle.html`.
2. In FlexiFunnels, add a **Custom Code** element onto a blank page.
3. Paste the code, save, and publish.
